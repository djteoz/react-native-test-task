## Задание №1

изменить компонент TobBar по [макету](https://www.figma.com/design/NQBdYXvFxHjdarHImVga5X/iOS-Nav-Bar-Variants--Community-?node-id=201-71&t=FpYf9qqOQCzSFeIJ-0).
начальный компонент для изменения находится  [тут](./components/TobBar)


### обратить внимание

1) если есть safearea.top то отступ сверху равен ему. если нет, то такой как на макете
2) в макете справа есть не только иконка, но и текст. у нас будет только иконка
3) передача кнопок должна происходить массивом с такими параметрами
   1) iconName: string - в проекте нет иконок. можно вместо использовать уже готовый компонент Icon
   2) onPress: () => void
4) навигация по кнопке назад должна происходить внутри компонента, а также можно передать кастомный обработчик на его нажатие
5) шрифт можно не подгружать в проект, использовать базовый, но размеры и вес нужно

### Финальный результат

1) Запись экрана симулятора с экраном TestScreen, на котором будет несколько видов топбаров. 
под разными видами подразумевается разные параметры в пропса 
   1) передается только title
   2) передается title + title кнопки назад
   3) передается только title и 1 кнопка(иконка) справа
   4) передается title + title кнопки назад + 1 кнопка(иконка) справа
   5) передается title + title кнопки назад + 3 кнопки(иконка) справа
2) залитый код на гитхаб или другой аналог. ссылка на него.
очень желательно, чтобы вся Ваша работа была оформлена в отдельный коммит, в котором
будет только ваша работа
